# Module 5 Examples

Hands-on **Icarus Verilog** demos for Module 5. Run from the course repo root unless noted.

---

## 1. Operators (`operators/`)

Build and simulate: `module5/examples/operators/`.

**Try these** (from repo root):

```bash
cd module5/examples/operators
make clean && make run
```
