# Module 4 Examples

Hands-on **Icarus Verilog** demos for Module 4. Run from the course repo root unless noted.

---

## 1. logic and 2-State Types (`data_types/`)

Build and simulate: `module4/examples/data_types/`.

**Try these** (from repo root):

```bash
cd module4/examples/data_types
make clean && make run
```
