# Module 1 Examples

Hands-on **Icarus Verilog** demos for Module 1. Run from the course repo root unless noted.

---

## 1. Modules and Ports (`modules_ports/`)

Build and simulate: `module1/examples/modules_ports/`.

**Try these** (from repo root):

```bash
cd module1/examples/modules_ports
make clean && make run
```
