# Module 2 Examples

Hands-on **Icarus Verilog** demos for Module 2. Run from the course repo root unless noted.

---

## 1. ANSI Ports (`ansi_ports/`)

Build and simulate: `module2/examples/ansi_ports/`.

**Try these** (from repo root):

```bash
cd module2/examples/ansi_ports
make clean && make run
```
