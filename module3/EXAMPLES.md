# Module 3 Examples

Hands-on **Icarus Verilog** demos for Module 3. Run from the course repo root unless noted.

## 1. Parameter Override (`parameters/`)

Build and simulate: `module3/examples/parameters/`.

**Try these** (from repo root):

```bash
cd module3/examples/parameters
make clean && make run
```
